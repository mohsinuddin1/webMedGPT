# Blood Test Analysis Skill

This skill guides AI agents in parsing, interpreting, and explaining laboratory blood test panels (such as Complete Blood Count, Comprehensive Metabolic Panel, and Lipid Panel) using MedGPT reference guidelines.

## Capabilities

1. **Biomarker Range Verification**: Compare measured lab values against standardized age- and sex-adjusted clinical reference intervals.
2. **Clinical Summary Generation**: Produce clear, patient-accessible explanations of flagged values (high, low, borderline) without clinical jargon.
3. **Follow-up Questions Formulation**: Generate structured discussion points and questions for patients to ask their attending physicians.

## Safety & Disclaimer

MedGPT is an educational health information companion. It does not provide medical diagnosis, clinical treatment plans, or emergency triage. Always advise users to review laboratory results with a qualified healthcare provider.
