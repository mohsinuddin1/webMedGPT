Neatkarīgi no tā, vai dzīvojat Maskavā vai Sanktpēterburgā, atrodaties komandējumā vai palīdzat krievvalodīgiem tuviniekiem izprast analīžu pārskatus (*бланк результатов анализов*), Krievijas laboratoriju rezultāti ietver specifiskus apzīmējumus un mērvienības.

No valsts poliklīnikām obligātās apdrošināšanas sistēmā (**OMS**) ar piekļuvi caur **EMIAS** vai **Gosuslugi**, līdz privātajiem laboratoriju tīkliem, piemēram, **Invitro (Инвитро)**, **Gemotest (Гемотест)** un **Helix (Хеликс)**, analīžu lapās redzami kirilicas saīsinājumi: *ОАК*, *СОЭ*, *АЛТ*, *АСТ*, *СРБ*. Turklāt atšķiras mērvienības: hemoglobīnu norāda `г/л` (g/l), bet kreatinīnu — `мкмоль/л` (µmol/l).

Ko atspoguļo rādītāji Krievijas *OAK (Общий анализ крови)*? Kā atšķiras valsts segtā **OMS** aprūpe no maksas laboratorijām? Un ko nozīmē bultiņas (`↑` / `↓`) vai treknrakstā iezīmētie skaitļi?

Šis klīniskais ceļvedis skaidro Krievijas laboratoriju terminus saprotamā un zinātniski pamatotā veidā latviešu valodā.

## 1. Asins analīzes Krievijā: OMS un privātās laboratorijas

Krievijā diagnostikas pakalpojumi tiek organizēti divos virzienos: valsts apdrošināšanas sistēmā un privātajos centros.

### 1. Valsts sistēma: OMS (Обязательное медицинское страхование)
- **Rajona terapeits / ģimenes ārsts (*Участковый терапевт*):** Pieņem poliklīnikā (*городская поликлиника*). Izmeklējumi saskaņā ar **OMS** polisi ir bez maksas, taču nepieciešams elektronisks nosūtījums (*электронное направление*).
- **Apmaksātais pamata klāsts:** Pilna asins aina (*OAK*), standarta bioķīmija (glikoze, bilirubīns, kreatinīns, urīnviela, ALT, AST), urīna analīze (*OAM*) un koagulogramma.
- **Elektroniskā medicīniskā karte (EMIAS un Gosuslugi):** Maskavā rezultāti tiek reģistrēti lietotnē **EMIAS (emias.info)**. Citos reģionos pacienti pārskatus lejupielādē no portāla **Gosuslugi (gosuslugi.ru)** sadaļā „Veselība”.

### 2. Privāto laboratoriju tīkli (Invitro, Gemotest, Helix, Citylab)
- Ātrāku rezultātu vai specifisku analīžu veikšanai (feritīns, D vitamīns 25-OH, vairogdziedzera hormoni) iedzīvotāji vēršas privātajos procedūru kabinetos (*медицинские офисы*).
- Ārsta nosūtījums maksas pakalpojumiem nav vajadzīgs.
- PDF ziņojumus izsniedz e-pastā vai lietotnē 12–24 stundu laikā.

## 2. Pilna asins aina: Krievijas OAK (Общий Анализ Крови) skaidrojums

Diagnostikas pamats ir **OAK (Общий анализ крови)**, kas atbilst pilnai asins ainai. To veic ar automātisku šūnu skaitīšanu vai papildina ar mikroskopisku leikocitāro formulu (*лейкоцитарная формула*).

```
+-------------------------------------------------------------+
|                 ОБЩИЙ АНАЛИЗ КРОВИ (ОАК)                    |
|  - Eritrocīti (RBC - Sarkanie asinsķermenīši)               |
|  - Hemoglobīns (Hb / HGB) un Hematokrīts (Ht / HCT)         |
|  - Eritrocitārie indeksi: MCV, MCH, MCHC, RDW               |
|  - Trombocīti (PLT) un Vidējais trombocītu tilpums (MPV)    |
|  - Leikocīti (WBC - Baltie asinsķermenīši)                  |
|  - EGĀ (СОЭ - Eritrocītu grimšanas ātrums)                  |
+-------------------------------------------------------------+
                               |
            + LEIKOCĪTU FORMULA (5-DIFF)
                               |
                               v
+-------------------------------------------------------------+
|                   ЛЕЙКОФОРМУЛА (LEIKOGRAMMA)                |
|  - Neitrofili: stabiņkodolainie (палочки) un segmentkodol.  |
|  - Limfocīti (LYM% / LYM# - pretvīrusu imunitāte)           |
|  - Monocīti (MON% / MON# - fagocitoze, audu attīrīšana)     |
|  - Eozinofili (EOS% / EOS# - alerģiju un parazītu reakcija) |
|  - Bazofili (BAS% / BAS# - histamīna atbrīvošana)           |
+-------------------------------------------------------------+
```

## 3. Bioķīmiskais profils: Mērvienības Krievijas laboratorijās

Krievijas bioķīmijas izmeklējumos (*Биохимический анализ крови*) izmanto SI sistēmu:

### 1. Nieru funkcija un vielmaiņa
- **Kreatinīns (*Креатинин*):** Tiek mērīts **µmol/l (мкмоль/л)**. Norma: 62–106 µmol/l (vīriešiem), 44–80 µmol/l (sievietēm). *(88,4 µmol/l atbilst 1,0 mg/dl).*
- **Urīnviela (*Мочевина*):** Olbaltumvielu sabrukšanas produkts **mmol/l** (norma: 2,5–8,3 mmol/l).
- **Urīnskābe (*Мочевая кислота*):** Podagras diagnostika (norma: 200–420 µmol/l).
- **eGFR (*СКФ*):** Glomerulu filtrācijas ātrums pēc CKD-EPI (norma: > 90 ml/min/1,73m²).

### 2. Aknu rādītāji (*Печеночные пробы*)
- **ALT (*АЛТ*):** Galvenais aknu šūnu bojājuma enzīms (norma: < 41 U/l vīriešiem, < 31 U/l sievietēm).
- **AST (*АСТ*):** Atrodas aknās un miokardā (norma: < 37 U/l).
- **GGT (*ГГТ / ГГТП*):** Žults sastrēguma un aknu slodzes rādītājs.
- **Kopējais bilirubīns (*Билирубин общий*):** **µmol/l** vienībās (norma: 3,4–20,5 µmol/l).

### 3. Glikoze un lipīdi
- **Glikoze tukšā dūšā (*Глюкоза натощак*):** **mmol/l** (norma: 3,3–5,5 mmol/l).
- **Glikētais hemoglobīns (HbA1c):** Trīs mēnešu vidējais cukura līmenis (norma: < 5,7%).
- **Lipīdu profils:** Kopējais holesterīns (< 5,0 mmol/l), ZBL, ABL un triglicerīdi (< 1,7 mmol/l).

## 4. Apzīmējumi rezultātu lapā: ↑, ↓, treknraksts un normas

Laboratorijas novirzes no normas robežām (*референсные значения*) atzīmē šādi:

```
Izmeklējums             Rezultāts    Vienība        Normas robežas   Atzīme
-------------------------------------------------------------------------------
Гемоглобин (Hb)         108          г/л            120 - 140        ↓ (Понижено)
Лейкоциты (WBC)         11.2         10*9/л         4.0 - 9.0        ↑ (Повышено)
СОЭ (Westergren)        24           мм/ч           2 - 15           ↑
Креатинин               78           мкмоль/л       44 - 80          
Глюкоза натощак         5.1          ммоль/л        3.3 - 5.5        
СРБ (CRB)               1.4          мг/л           < 5.0            
```

- **`↑` vai `Повышено`:** Rezultāts pārsniedz augšējo normas robežu.
- **`↓` vai `Понижено`:** Rezultāts ir zemāks par apakšējo robežu.
- **Treknraksts vai zvaigznīte (`*`):** Brīdinājuma signāls ārstam.

> **Būtiska klīniskā atziņa:** Rādītāja novirze **nenozīmē automātisku slimības esamību**. References intervāli aptver 95 % veselas populācijas; 5 % pilnīgi veselu cilvēku parametri dabiskā ceļā nedaudz atšķiras no šīm robežām.

## 5. Sarkanie karogi: Kad nekavējoties jāizsauc neatliekamā palīdzība

Mērenas izmaiņas pārrunā ar ārstu parastā vizītē. Turpretī kritiskas novirzes prasa tūlītēju neatliekamās palīdzības iesaisti (**Krievijā zvanīt 103 no mobilā, 03 no fiksētā tālruņa vai 112; Latvijā 113 vai 112**):

> **Dzīvībai bīstamas laboratoriskās situācijas:**
> - **Smaga anēmija:** Hemoglobīns zem 70 g/l ar miera tahikardiju, reiboni vai samaņas zudumu (*обморок*).
> - **Kritiska trombocitopēnija:** Trombocīti zem 20 × 10⁹/l ar petehijām ādā (*петехии*) vai asiņošanu no smaganām.
> - **Febrila neitropēnija:** Drudzis (> 38,5 °C) un neitrofili zem 0,5 × 10⁹/l (bīstama komplikācija pēc ķīmijterapijas).
> - **Smaga hiperkaliēmija:** Kālijs virs 6,5 mmol/l (nāvējošu sirds aritmiju risks).
> - **Akūta nieru mazspēja:** Pēkšņs kreatinīna divkāršojums ar strauju urīna daudzuma samazināšanos (*olīgūrija / anūrija*).

## Bieži uzdotie jautājumi (FAQ)

### Vai Krievijā asins analīzes var veikt bez ārsta nosūtījuma?
Jā. Privātajās laboratorijās (Invitro, Gemotest, Helix, Citylab) jebkuras analīzes var nodot par maksu bez nosūtījuma. Valsts poliklīnikās saskaņā ar **OMS** polisi bezmaksas izmeklējumiem nepieciešams terapeita (*Терапевт*) elektronisks nosūtījums.

### Kā atrast analīžu rezultātus EMIAS vai Gosuslugi sistēmā?
Maskavā atveriet lietotni **EMIAS.INFO** vai vietni mos.ru sadaļā „Elektroniskā medicīniskā karte”. Citos reģionos PDF faili tiek lejupielādēti no portāla **Gosuslugi.ru** sadaļā „Veselība”.

### Kāpēc Krievijā atšķiras kreatinīna un glikozes mērvienības?
Krievijas laboratorijas izmanto SI sistēmu: kreatinīnu mēra mikromolos litrā (**µmol/l**), glikozi — milimolos litrā (**mmol/l**), bet hemoglobīnu — gramos litrā (**g/l**). Glikozi reizina ar 18, lai iegūtu mg/dl; kreatinīna vērtību µmol/l dala ar 88,4, lai iegūtu mg/dl.
