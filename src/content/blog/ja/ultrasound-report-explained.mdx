薄暗い検査室のベッドに横たわると、検査技師や医師が温かい透明なゼリーをお腹、首、下腹部に塗り、プローブ（超音波探触子）を肌に軽く押し当てながら滑らせます。機器からシュッシュッというリズミカルな血流音が響き、目の前のモニターにはリアルタイムで動く白黒の断層画像が映し出されます。数日後、検査結果の用紙を開くと、そこには聞き慣れない専門用語が並んでいます。

報告書を読むと、戸惑うような表現が目に入ります。*「肝実質はびまん性にエコー輝度亢進を認め、脂肪肝に合致する（Bright Liver）」*、*「胆嚢内腔に体位変換で可動する音響陰影（アコースティックシャドウ）を伴う高エコー結石を認む」*、*「左卵巣に後方エコー増強を伴う32mmの無エコー性単純嚢胞」*、あるいは*「右甲状腺葉に充実性低エコー結節あり、ACR TI-RADS 4相当」*。

「エコー輝度亢進」とは悪性腫瘍のことなのでしょうか？ 痛みのない胆石はすぐに手術すべきでしょうか？ TI-RADS 4やO-RADS 2といったスコアは何を意味しているのでしょうか？

本ガイドでは、医師がエコー画像をどのように読み解いているのか、難解な用語の意味、放射線被曝に関する真実、そして直ちに救急受診が必要な危険なサインまで分かりやすく解説します。

## 超音波検査の物理：エコー輝度（白黒の濃淡）を理解する

X線（レントゲン）やCT検査とは異なり、エコー検査では**放射線被曝が一切ありません**。プローブから人の耳には聞こえない高周波の音波（通常2〜15 MHz）を生体内に発信します。音波が異なる組織の境界に衝突すると、一部が反射して「エコー（反響音）」として戻り、残りはさらに深部へと進みます。

モニター上で臓器がどれほど明るく描出されるかは、その組織の**エコー輝度（音波を跳ね返す強さ）**によって決まります：

- **無エコー（アンエコーイック / 真っ黒）：** 均一な透明な液体は、音波を減衰も反射もさせずに完全に素通りさせます。そのため画面上では完全な黒として映ります。典型例：尿で満たされた膀胱、胆汁、単純性嚢胞の液体、腹水、太い血管内の血液。
- **低エコー（ハイポエコーイック / 暗いグレー）：** 周囲の正常組織よりも音波の反射が少ない部分です。リンパ節、充実性悪性腫瘍、橋本病などの慢性甲状腺炎、急性炎症による局所浮腫、筋肉組織に多く見られます。
- **等エコー（アイソエコーイック / 中間のグレー）：** 比較対象となる正常な実質組織とまったく同じ明るさで音波を反射します。肝臓や甲状腺の良性結節の多くは等エコーであり、周囲組織と自然に溶け合って見えます。
- **高エコー（ハイパーエコーイック / 明るい白）：** 音響抵抗が非常に高く、音波の大部分を強力に跳ね返す高密度な構造物です。典型例：胆石、腎結石、骨の表面、石灰化病変、および脂肪組織（脂肪肝で見られる白く輝く肝臓「Bright Liver」など）。

```
+-----------------------------------------------------------------------------------+
|                        超音波エコー検査の輝度スペクトラム                         |
+-----------------------------------------------------------------------------------+
|  【完全な黒（無エコー）】    --> 透明な液体：尿、胆汁、単純性嚢胞、血管内血液      |
|  【暗いグレー（低エコー）】  --> 軟部組織：リンパ節、充実性腫瘍、浮腫、筋肉        |
|  【中間のグレー（等エコー）】--> 正常実質組織：健康な肝臓、脾臓                    |
|  【明るい白（高エコー）】    --> 高密度/脂肪/カルシウム：結石、骨、脂肪肝          |
+-----------------------------------------------------------------------------------+
```

### 重要な音響アーチファクト：音響陰影 vs 後方増強

画像診断医は、病変が「硬い石」なのか「水が溜まった嚢胞」なのかを見分けるために、2大音響現象を活用します：

1. **後方音響陰影（アコースティックシャドウ / 白い影の後ろの黒い帯）：** カルシウムが沈着した硬い結石（胆石や腎結石）は、超音波ビームを完全に遮断します。結石の裏側には音波が一切届かないため、その直下にシャープな真っ黒い影が伸びます。後方音響陰影を伴う高エコー構造は、結石（胆石や腎結石）が存在する決定的な証拠です。
2. **後方エコー増強（黒い影の後ろの明るい帯）：** 嚢胞内の液体は音波をほとんど減衰させません。超音波が液体嚢胞を通過して後方の組織に達したとき、隣接する実質組織を通った音波よりも多くのエネルギーを保持しています。そのため、嚢胞のすぐ後ろの組織が周囲より白く明るく見えます。これにより、病変が固形腫瘍ではなく良性の単純嚢胞であると確定できます。

## カラードプラ：赤、青、そして血流の真実

検査中に**カラードプラ（Color Doppler）**機能を作動させると、画面上に赤や青の鮮やかな色彩が点滅します。「赤は動脈血で青は静脈血」という誤解が非常に多いですが、そうではありません。

実際の色は、単に**プローブに対する血流の向き**を示しています：
- **BARTルール：** **B**lue **A**way（青はプローブから遠ざかる血流）、 **R**ed **T**owards（赤はプローブに向かって近づく血流）。
- **結節の血管網パターン：** 血管の走行は良悪性の鑑別に極めて重要です。結節の周囲をリング状に取り囲む辺縁血流（Halo）は良性所見であることが多く、逆に結節の中心部に不規則に乱れ飛ぶ血流（中心性多血性）は慎重な精査が必要です。
- **パルスドプラ：** 血流の最高速度や血管抵抗指数（RI）を計測し、深部静脈血栓症（DVT）や腎動脈狭窄症の診断に役立ちます。

## 最も代表的な3大エコー検査を徹底解説

### 1. 腹部エコー検査：肝臓・胆嚢・腎臓・脾臓

みぞおちの痛み、健診での肝機能酵素（AST, ALT, γ-GTP）異常、背部痛の際に行われる第一選択の検査です：

| 検査対象臓器 | 正常像 | 報告書の代表的記載 | 医学的意義 |
| :--- | :--- | :--- | :--- |
| **肝臓** | 辺縁整、実質均一、右葉最大長 15〜16 cm 未満 | *びまん性エコー輝度亢進（Bright Liver）* | 脂肪肝（肝脂肪沈着症）。細胞内の脂肪滴が超音波を強く散乱させます。 |
| **肝限局性病変** | 病変なし | *境界明瞭な類円形の均一な高エコー結節* | 肝血管腫（極めて頻度の高い良性血管性腫瘍であり、無害な経過観察対象）。 |
| **胆嚢** | 内腔無エコー、壁厚 3 mm 未満 | *音響陰影を伴う可動性高エコー* | 胆石症（胆嚢結石）。体位変換でゴロゴロ動くことで固定されたポリープを除外。 |
| **胆管** | 総胆管径 6 mm 未満 | *総胆管拡張（例：9 mm）と胆泥* | 胆汁うっ滞（閉塞性黄疸）。総胆管の出口付近に結石が詰まっている疑い。 |
| **腎臓** | 長径 9〜12 cm、皮質厚 1 cm 以上 | *腎盂腎杯拡張（水腎症 / Hydronephrosis）* | 尿管に結石が詰まり、腎臓内に尿が逆流して風船のように腫れている状態。 |
| **腹部大動脈** | 血管径 3.0 cm 未満 | *紡錘状または嚢状拡張（径 3.0 cm 以上）* | 腹部大動脈瘤（AAA）。径の大きさにより定期観察または手術適応を判断。 |

### 2. 骨盤エコー・経膣エコー：子宮・子宮内膜・卵巣

経腹超音波（尿を溜めて音響窓を作ります）および経膣超音波（高解像度観察）で実施されます：

- **子宮内膜の厚み：** 月経周期によってダイナミックに変化します。閉経後の不正出血がない女性では、正常な厚みは 4〜5 mm 未満です。閉経後に内膜が異常肥厚・不均一化している場合は、子宮内膜増殖症や子宮体がんを除外するため内膜細胞診・組織診が必要です。
- **子宮筋腫（平滑筋腫）：** 子宮筋層にできる非常にありふれた良性腫瘍です。局在により分類されます：*粘膜下筋腫*（内腔に突出し過多月経の原因になりやすい）、*筋層内筋腫*（子宮筋の壁の中）、*漿膜下筋腫*（子宮の外側へ発育）。
- **卵巣嚢腫とO-RADS：**
  - *機能性嚢胞：* 単房性・薄壁の単純嚢胞で、多くは1〜3回の月経周期で自然消失します。
  - *チョコレート嚢胞（子宮内膜症性嚢胞）：* スリガラス状の均一な低エコー点状陰影が充満。
  - *皮様嚢腫（奇形腫 / デルモイド）：* 内部に脂肪・毛髪・歯牙を含む高エコー塊と陰影。
  - *O-RADSスコア：* O-RADS 1（正常卵巣）から O-RADS 5（悪性疑い・婦人科腫瘍専門医への紹介要）までリスクを段階評価。

### 3. 甲状腺エコーとTI-RADSシステム

甲状腺は首の喉仏の下、皮膚の浅い位置にあるため、超音波で細部まで明瞭に観察できます。成人の50%以上に無症状の微小な「偶発結節（甲状腺のしこり）」が見つかります。

良性の無害な結節に対する不要な針生検（穿刺吸引細胞診）を防ぐため、**ACR TI-RADS / 日本甲状腺学会基準**では5つの項目でポイントを付けます：

1. **性状（Composition）：** 嚢胞性/海綿状（0点）、混合性（1点）、充実性（2点）。
2. **エコー輝度（Echogenicity）：** 無エコー（0点）、高/等エコー（1点）、低エコー（2点）、著明な低エコー（3点）。
3. **形状（Shape）：** 横長（0点）、前後径が横径より大きい縦長形状（3点、悪性疑い徴候）。
4. **境界（Margin）：** 整・明瞭（0点）、微細分葉状/不正（2点）、甲状腺外浸潤（3点）。
5. **高エコー斑（Foci）：** コメット様アーチファクト（0点、膠質）、粗大石灰化（1点）、辺縁石灰化（2点）、微細点状高エコー（3点、微小石灰化）。

```
+-----------------------------------------------------------------------------------+
|                        ACR TI-RADS によるリスク層別化                             |
+-----------------------------------------------------------------------------------+
|  TR1: 0点     --> 良性（がんの確率 0.3% 未満） — 穿刺生検は不要                    |
|  TR2: 2点     --> 悪性疑いなし（確率 1.5%） — 生検不要                           |
|  TR3: 3点     --> 低度疑い（確率 4.8%） — 長径 ≥ 25 mm で細胞診を考慮              |
|  TR4: 4〜6点  --> 中等度疑い（確率 9.1%） — 長径 ≥ 15 mm で細胞診を推奨           |
|  TR5: 7点以上 --> 高度悪性疑い（確率 35%） — 長径 ≥ 10 mm で細胞診を実施          |
+-----------------------------------------------------------------------------------+
```

## 検査報告書によくあるエコー用語集

| 報告書の記載用語 | わかりやすい日本語の意味 | 次に行うべき対応 |
| :--- | :--- | :--- |
| **「特記すべき異常所見なし（N.P.）」** | 観察したすべての臓器が、形態・大きさ・実質構造ともに正常範囲内です。 | 追加の画像検査は不要です。 |
| **「実質エコー均一（Homogeneous）」** | 臓器の内部組織がきめ細かく滑らかで健康な状態です。 | 正常で安心できる所見です。 |
| **「実質粗糙 / エコー不均一」** | 組織に斑状の乱れやざらつきが見られます。 | 脂肪肝、慢性肝炎、慢性甲状腺炎などの存在を示唆します。 |
| **「超音波マーフィー徴候陽性」** | 画面に映る胆嚢の真上をプローブで圧迫した際に、局所的な強い激痛が生じる状態。 | 急性胆嚢炎（胆嚢の急性炎症）の決定的兆候です。 |
| **「腎盂拡張 / 水腎症」** | 尿管の通過障害により、腎臓内に尿が溜まり腫れ上がっている状態。 | 尿管結石を疑い、泌尿器科での精密検査が必要です。 |
| **「ダグラス窩遊離液体（腹水）」** | 骨盤内の最も低い位置（子宮と直腸の間のくぼみ）に液体が溜まっている状態。 | 排卵期の微量貯留は生理的正常ですが、多量の場合は嚢胞破裂や出血を疑います。 |

## 超音波の安全性：放射線被曝の危険性はあるか？

「何度もエコー検査を受けて体に悪影響はないのか？」と心配される患者様は少なくありません。医学的な結論は明確です。**エコー検査に放射線リスクは一切ありません**：

- **ゼロ放射線被曝：** レントゲンやCTのような電离放射線は使用せず、潜水艦のソナーと同じ無害な音波のみを使用します。
- **妊娠中や乳幼児にも完全安全：** 胎児の形態観察のために産婦人科で60年以上にわたり日常的に行われていますが、胎児の遺伝子や発達への有害事象は一件も報告されていません。
- **熱指数・機械指数（TI / MI）：** 医療用エコー装置はALARAの原則に基づき出力を自動制御しており、生体組織の温度上昇が起きないよう安全設計されています。

## 危険な赤信号（レッドフラッグ）：直ちに救急受診すべき状況

エコー所見の大半は良性または慢性疾患ですが、以下の所見を認める場合は救急外来での緊急治療が必要です：

> [!CAUTION]
> **直ちに緊急処置が必要な超音波所見：**
> 1. **結石嵌頓を伴う急性胆嚢炎：** 胆嚢壁が 3 mm 以上に肥厚し二重構造を呈し、周囲に浸出液があり、マーフィー徴候陽性で高熱を伴う場合。
> 2. **卵巣茎捻転・精巣捻転の疑い：** 臓器が高度に腫脹・浮腫化し、カラードプラで動脈および静脈血流が完全に途絶え、激痛が生じている場合。
> 3. **異所性妊娠（子宮外妊娠）破裂：** 妊娠反応陽性にもかかわらず子宮内が空虚で、卵管付近に腫瘤があり、骨盤内に多量の血性腹水（出血）が認められる場合。
> 4. **閉塞性感染性水腎症：** 結石による尿路閉塞で腎盂がパンパンに腫れ、悪寒戦慄、38.5℃以上の高熱、側腹部痛を伴う場合（敗血症の危機）。
> 5. **切迫破裂の腹部大動脈瘤：** 大動脈径が 55 mm を超え、突然の激しい腰背部痛を伴う場合。

## 4ステップ行動指針：エコー報告書をどう役立てるか

1. **まず末尾の「診断 / 所見総括（Impression）」を読む：** 本文にはミリ単位の細かな数値が並んでいますが、診断医の最終的な医学的結論は最後の「総括」に集約されています。
2. **過去のエコー結果と比較する：** 大きさや性状に変化がない「不変」は、良性である最大の証明です。3年間大きさが変わらない2cmの血管腫や甲状腺結節は、治療を要しないケースが大半です。
3. **主治医への具体的な質問を用意する：**
   - *「今回のエコーで見つかった所見は、私が自覚している症状と関係がありますか？」*
   - *«TI-RADSやO-RADSのスコアから見て、細胞診（針生検）が必要ですか、それとも半年〜1年後の経過観察で十分ですか？»*
