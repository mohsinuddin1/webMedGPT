デュッセルドルフ、フランクフルト、ミュンヘン、ベルリンなど、ドイツに在住・駐在する日本人にとって、現地の家庭医（*Hausarzt*）を受診した後に受け取る検査結果用紙（*Laborbefund*）は、見慣れないドイツ語の略語で溢れています。

紙の検査票や、公的医療保険（*TK*、*Barmer*、*AOK*、*DAK*など）のアプリ**「ePA（Elektronische Patientenakte）」**を開くと、*BSG*、*o.p.B.*、*GPT*、*gamma-GT*などの文字や、数値の横に「`+`」「`-`」「`*`」の記号が並んでいます。

「*kleines Blutbild*」と「*großes Blutbild*」は何が違うのか？ プラスやマイナスの記号は病気を意味するのか？ そして、どのような異常値が出た場合に救急受診が必要なのか？

## 1. ドイツの電子カルテ「ePA（Elektronische Patientenakte）」とは？

ドイツの医療デジタル化法（*DigiG*）に基づき、公的医療保険（*GKV*）加入者全員を対象に**「誰でも使えるePA（ePA für alle）」**の導入が進められています。

### 日常生活でのePAの役割：

スマートフォンアプリを通じて、自身の医療データを一元管理できます：

- **検査結果のデジタル連携：** Synlab、Limbach、Bioscientiaなどの主要検査機関から、医師の承認後に構造化データとしてアプリへ即時送信されます。
- **医師の診断書・紹介状（*Arztbriefe*）：** 入院時の退院サマリー、専門医の所見、画像診断結果（超音波、X線、MRI）。
- **投薬計画表（*BMP*）：** 電子処方箋（*E-Rezept*）と連動し、危険な薬の飲み合わせを防止します。
- **予防接種手帳（*Impfpass*）や歯科検診記録。**

検査結果が医師の診察前にアプリに届くため、基準値からわずかに外れた数値を見て過度な不安を抱く患者さんも増えています。

## 2. kleines Blutbild と großes Blutbild の決定的な違い

ドイツで医師が「血算（Blutbild）」をオーダーする場合、基本血算（*kleines Blutbild*）か、白血球分画を含む全血算（*großes Blutbild*）のいずれかを指定します。

```
+-------------------------------------------------------------+
|                     KLEINES BLUTBILD                        |
|  - Erythrozyten（赤血球数）                                  |
|  - Hämoglobin（Hb: ヘモグロビン量）& Hämatokrit（ヘマトクリット）
|  - 赤血球恒数：MCV、MCH、MCHC                               |
|  - Thrombozyten（血小板数）                                 |
|  - Leukozyten gesamt（総白血球数）                           |
+-------------------------------------------------------------+
                               |
                   + DIFFERENZIALBLUTBILD
                               |
                               v
+-------------------------------------------------------------+
|                      GROSSES BLUTBILD                       |
|  kleines Blutbildの全項目に加えて、白血球内訳を精密測定：   |
|  - Neutrophile Granulozyten（好中球：分葉核／桿状核）       |
|  - Lymphozyten（リンパ球：ウイルス防御・抗体産生）          |
|  - Monozyten（単球：組織マクロファージの前駆細胞）          |
|  - Eosinophile Granulozyten（好酸球：アレルギー・寄生虫対応）|
|  - Basophile Granulozyten（好塩基球：ヒスタミン放出）       |
+-------------------------------------------------------------+
```

### 項目比較表

| 検査項目 | ドイツ語表記 | kleines | großes | 主な生理的役割 |
| :--- | :--- | :---: | :---: | :--- |
| **赤血球数** | *Erythrozyten (Ery)* | 含む | 含む | 全身の細胞・組織への酸素運搬 |
| **ヘモグロビン** | *Hämoglobin (Hb)* | 含む | 含む | 酸素を結合する鉄含有タンパク質 |
| **ヘマトクリット** | *Hämatokrit (Hkt)* | 含む | 含む | 血液全体に占める血球容積の割合 |
| **赤血球恒数** | *MCV, MCH, MCHC* | 含む | 含む | 貧血の種類（小球性・正球性・大球性）の判定 |
| **血小板数** | *Thrombozyten (Thro)* | 含む | 含む | 止血作用および血液凝固 |
| **総白血球数** | *Leukozyten (Leukos)* | 含む | 含む | 体内に入った病原体に対する免疫防御 |
| **好中球** | *Neutrophile Granulozyten* | 含まない | **含む** | 急性細菌感染に対する初期防御 |
| **リンパ球** | *Lymphozyten* | 含まない | **含む** | ウイルス感染の防御および免疫記憶 |
| **単球** | *Monozyten* | 含まない | **含む** | 異物貪食および慢性炎症の修復 |
| **好酸球** | *Eosinophile* | 含まない | **含む** | アレルギー反応および寄生虫に対する防御 |
| **好塩基球** | *Basophile* | 含まない | **含む** | 炎症時のヒスタミン放出 |

## 3. ドイツの検査票に頻出する略語辞典

ドイツの検査結果用紙（*Laborbefund*）には、日本のカルテとは異なる特有の略語が使用されます：

### 1. 炎症・一般マーカー
- **BSG（*Blutkörperchensenkungsgeschwindigkeit*）:** 赤血球沈降速度（赤沈・ESR）。慢性炎症や膠原病の指標。
- **CRP（*C-reaktives Protein*）:** C反応性タンパク。細菌感染や組織破壊で急速に上昇。
- **o.b.B. / o.p.B.（*ohne pathologischen Befund*）:** 「病的所見なし」。異常がなく極めて健康であることを意味します。

### 2. 肝機能検査（*Leberwerte*）
- **GOT / AST（*Glutamat-Oxalacetat-Transaminase / AST*）:** 肝細胞や心筋に存在する酵素。
- **GPT / ALT（*Glutamat-Pyruvat-Transaminase / ALT*）:** 肝細胞の傷害を最も特異的に反映する最重要指標。
- **gamma-GT（*Gamma-Glutamyltransferase*）:** 胆道系疾患、アルコール摂取、薬剤の影響に敏感に反応する酵素。
- **AP（*Alkalische Phosphatase*）:** アルカリフォスファターゼ（胆道系や骨疾患）。

### 3. 腎機能・電解質（*Nierenwerte*）
- **Krea（*Kreatinin*）:** 血清クレアチニン。筋肉代謝産物で、腎臓から排泄されます。
- **eGFR（*geschätzte glomeruläre Filtrationsrate*）:** 推算糸球体濾過量。90 mL/min以上が正常値。
- **Harnstoff:** 尿素窒素（BUN）。
- **Harnsäure:** 尿酸値（高尿酸血症・痛風の診断に不可欠）。

### 4. 糖代謝および凝固検査
- **BZ（*Blutzucker*）:** 空腹時血糖値（西ドイツでは主に `mg/dl`、東部では稀に `mmol/l`）。
- **HbA1c（*Langzeit-Blutzucker*）:** 過去1〜2ヶ月間の平均血糖状態を反映する指標。
- **TSH basal（*Thyreoidea-stimulierendes Hormon*）:** 甲状腺刺激ホルモン。
- **Quick-Wert / INR:** プロトロンビン時間。抗凝固薬服薬時のモニタリング値。

## 4. プラス（+）、マイナス（-）、アスタリスク（*）の意味

ドイツの検査票では、統計的基準範囲（*Referenzbereich*）から外れた項目に目印が付けられます：

```
項目名               測定値     単位          基準値範囲         目印
-------------------------------------------------------------------------------
Leukozyten           11.6       /nl           3.9 - 10.2         + （または H / *）
Hämoglobin           14.2       g/dl          13.5 - 17.5        
Thrombozyten         142        /nl           150 - 370          - （または L）
ALAT (GPT)           30         U/l           < 50               
Kreatinin            0.90       mg/dl         0.70 - 1.20        
CRP                  1.0        mg/l          < 5.0              
```

- **`+` または `H`（Hoch）:** 基準値の上限を超えている状態。
- **`-` または `L`（Niedrig）:** 基準値の下限を下回っている状態。
- **`*`（Sternchen）:** 医師に対して確認を促す注意喚起フラグ。

> **臨床上の重要な鉄則:** 「`+`」や「`-`」がついているからといって、**直ちに深刻な病気であることを意味するわけではありません**。基準範囲は健康な人の95%が含まれるように統計学的に設定されており、完全な健康体であっても5%の人はわずかに範囲外の数値を記録します。

## 5. 自費診療の「IGeL（Individuelle Gesundheitsleistungen）」とは？

ドイツの公的医療保険（GKV）は、医学的に必要と認められた検査費用を100%カバーします。しかし、患者の希望による予防的追加検査は**「IGeL」**と呼ばれる自己負担メニューとなります：

- **ビタミンD（25-OH-D）検査:** 骨粗鬆症等の診断がない場合、約20〜35ユーロの自己負担。
- **PSA（前立腺特異抗原）検査:** 前立腺がんスクリーニング（約15〜25ユーロ）。
- **詳細な脂質分画（ApoB、Lp(a)など）:** 家族性高コレステロール血症の疑いがない場合。

## 6. 即座に救急受診すべきレッドフラッグ（危険兆候）

大半の検査値異常は軽微であり、次回の定期診察で相談すれば十分です。しかし、以下の緊急値が見られる場合は、迷わず最寄りの病院救急外来（*Notaufnahme* または **112**番）へ連絡してください：

> **生命に関わる緊急検査異常値：**
> - **重度の貧血:** ヘモグロビン（Hb）7.0 g/dl未満で、激しいめまいや息切れ、胸痛を伴う場合。
> - **重度の血小板減少:** 血小板20,000/µl未満で、皮膚の点状出血（紫斑）や歯肉出血が見られる場合。
> - **発熱性好中球減少症:** 好中球数が500/µl未満の状態で38.5℃以上の発熱（化学療法中など極めて危険）。
> - **重症高カリウム血症:** 血清カリウムが6.5 mmol/l以上（不整脈・心停止のリスク）。
> - **急性腎不全:** クレアチニン値が急激に2倍以上に上昇し、尿量が著しく減少している場合。

## よくある質問（FAQ）

### 血液検査におけるGKV（公的保険）とPKV（プライベート保険）の違いは？
公的保険（GKV）は医学的適応のある検査や国が定めた定期健診（Check-up 35など）をカバーします。プライベート保険（PKV）は加入プランに応じて、より広範な予防検査費用をカバーします。

### ドイツでは医師の処方箋なしで血液検査を受けられますか？
はい。主要都市にあるダイレクトラボ（*Direktlabor*）では自己負担（*Selbstzahler*）で直接採血を受けられます。ただし、数値の総合判定は必ず医師と共に行ってください。
