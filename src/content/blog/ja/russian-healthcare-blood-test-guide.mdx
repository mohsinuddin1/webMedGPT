モスクワやサンクトペテルブルクに滞在する駐在員や留学生、あるいはロシア語圏の家族の診断書（*бланк результатов анализов*）を確認する際、キリル文字で書かれたロシアの血液検査票を読み解くには独自の知識が必要です。

公的医療保険（**OMS**）に基づく国公立ポリクリニカ（モスクワの **EMIAS** や国家ポータル **Gosuslugi**）から、**Invitro (Инвитро)**、**Gemotest (Гемотест)**、**Helix (Хеликс)** などの民間大手ラボチェーンまで、検査票には *ОАК*、*СОЭ*、*АЛТ*、*АСТ*、*СРБ* といった略称が並びます。また、ヘモグロビンは `г/л` (g/l)、クレアチニンは `мкмоль/л` (µmol/l) で表記されるなど、日本（g/dL、mg/dL）とは測定単位が異なります。

ロシアの基本血液検査 *OAK (Общий анализ крови)* には何が記載されているのか？公的医療保険 **OMS** と民間検査所の違いは何か？そして矢印（`↑` / `↓`）や太字の数値は何を意味するのか？

本記事では、ロシアの検査票の専門用語と数値を医学的知見に基づき分かりやすく解説します。

## 1. ロシアの血液検査システム：OMS公的保険と民間検査所

ロシアの臨床検査は、国営の公的保険システムと民間の診断ネットワークの2つで運営されています。

### 1. 公的保険制度：OMS (Обязательное медицинское страхование)
- **地区担当内科医 (*Участковый терапевт*)：** 地域の公立診療所（*городская поликлиника*）で総合診療を行います。**OMS** 保険適用により検査費は無料ですが、公式の電子紹介状（*электронное направление*）が必要です。
- **保険適用の標準検査項目：** 血算（*OAK*）、基本生化学（血糖、ビリルビン、クレアチニン、尿素、ALT、AST）、尿一般（*OAM*）、凝固検査。
- **電子カルテポータル（EMIASおよびGosuslugi）：** モスクワ市内では **EMIAS (emias.info)** アプリに検査結果が直接反映されます。その他の地域では連邦ポータル **Gosuslugi (gosuslugi.ru)** の「健康」項目からダウンロードします。

### 2. 民間検査所ネットワーク（Invitro、Gemotest、Helix、Citylab）
- 迅速な検査結果や精密検査（フェリチン、ビタミンD 25-OH、甲状腺ホルモン等）を希望する場合、市中の採血オフィス（*медицинские офисы*）を利用します。
- 自費診療のため医師の紹介状は不要で、希望する検査を自由に受けられます。
- 結果は12〜24時間以内にPDF形式でメールや公式アプリに届きます。

## 2. 血算（CBC）：ロシアのOAK（Общий Анализ Крови）を読み解く

診療の基本となるのが **OAK (Общий анализ крови)**、すなわち全血球計算（血算）です。自動血球計数に加え、顕微鏡による白血球分画検査（*лейкоцитарная формула*）が併せて実施されます。

```
+-------------------------------------------------------------+
|                 ОБЩИЙ АНАЛИЗ КРОВИ (ОАК)                    |
|  - 赤血球数 (RBC - Красные кровяные тельца)                 |
|  - ヘモグロビン (Hb / HGB) ＆ ヘマトクリット (Ht / HCT)     |
|  - 赤血球恒数：MCV (平均赤血球容積)、MCH、MCHC、RDW         |
|  - 血小板数 (PLT) ＆ 平均血小板容積 (MPV)                   |
|  - 白血球数 (WBC - Белые кровяные тельца)                   |
|  - 赤沈 / ESR (СОЭ - 赤血球沈降速度)                        |
+-------------------------------------------------------------+
                               |
            + 白血球分画（5分類ディファレンシャル）
                               |
                               v
+-------------------------------------------------------------+
|                   ЛЕЙКОФОРМУЛА (白細胞分画)                 |
|  - 好中球：桿状核球 (палочки 幼若) ＆ 分葉核球 (сегменты)   |
|  - リンパ球 (LYM% / LYM# - ウイルス免疫・抗体産生)          |
|  - 単球 (MON% / MON# - 貪食作用・組織清掃)                  |
|  - 好酸球 (EOS% / EOS# - アレルギー・寄生虫反応)            |
|  - 好塩基球 (BAS% / BAS# - ヒスタミン放出)                  |
+-------------------------------------------------------------+
```

### OAKの主要項目と基準範囲

| 項目名 | ロシア語略称 | 現地単位 | 基準範囲 | 臨床的意義 |
| :--- | :--- | :---: | :---: | :--- |
| **赤血球数** | *Эритроциты (RBC)* | 10¹²/l | 4.0–5.1 (男) / 3.7–4.7 (女) | 酸素運搬能力。脱水や多血症で増加 |
| **ヘモグロビン** | *Гемоглобин (Hb)* | g/l | 130–160 (男) / 120–140 (女) | 酸素結合タンパク。低下は貧血（130 g/l = 13.0 g/dL） |
| **ヘマトクリット** | *Гематокрит (Ht)* | % | 39–49% (男) / 35–45% (女) | 全血液量に占める赤血球の容積比 |
| **MCV** | *MCV* | fl | 80–100 fl | 赤血球の大きさ：小球性 (< 80) vs 大球性 (> 100) |
| **血小板数** | *Тромбоциты (PLT)* | 10⁹/l | 150–400 × 10⁹/l | 止血作用。血小板減少症で低下し出血傾向 |
| **白血球数** | *Лейкоциты (WBC)* | 10⁹/l | 4.0–9.0 × 10⁹/l | 免疫防御。細菌感染や炎症で上昇 |
| **桿状核好中球** | *Палочкоядерные* | % | 1–6% | 未成熟な好中球。上昇（左方移動）は急性細菌感染を示唆 |
| **分葉核好中球** | *Сегментоядерные* | % | 47–72% | 成熟した好中球で、細菌感染防御の主力を担う |
| **リンパ球** | *Лимфоциты (LYM)* | % | 19–37% | ウイルス感染に対する免疫および抗体産生 |
| **単球** | *Моноциты (MON)* | % | 3–11% | 組織マクロファージとして感染残屑を清掃 |
| **好酸球** | *Эозинофилы (EOS)* | % | 0.5–5.0% | アレルギー性疾患、喘息、寄生虫感染の指標 |
| **赤沈 (СОЭ)** | *Скорость оседания* | mm/h | 1–10 (男) / 2–15 (女) | 赤血球沈降速度（パンチェンコフ法またはウェスターグレン法） |

## 3. 生化学検査：ロシアの測定単位と換算

ロシアの生化学検査（*Биохимический анализ крови*）では国際単位（SI）が採用されています：

### 1. 腎機能と代謝指標
- **クレアチニン (*Креатинин*)：** 日本の mg/dL とは異なり、**µmol/l (мкмоль/л)** で測定されます。基準値：男性 62–106 µmol/l、女性 44–80 µmol/l。*(換算：88.4 µmol/l ≒ 1.0 mg/dL)*。
- **尿素 (*Мочевина*)：** タンパク質代謝物で単位は **mmol/l**（基準値：2.5–8.3 mmol/l）。
- **尿酸 (*Мочевая кислота*)：** 痛風スクリーニング（基準値：200–420 µmol/l）。
- **eGFR (*СКФ*)：** CKD-EPI式による推算糸球体濾過量（正常値 > 90 ml/min/1.73m²）。

### 2. 肝機能指標 (*Печеночные пробы*)
- **ALT (*АЛТ*)：** 肝細胞障害の最も特異的な酵素（基準値：男性 < 41 U/l、女性 < 31 U/l）。
- **AST (*АСТ*)：** 肝臓や心筋に存在（基準値：< 37 U/l）。
- **GGT (*ГГТ / ГГТП*):** 胆汁うっ滞やアルコール・薬剤負荷の鋭敏な指標。
- **総ビリルビン (*Билирубин общий*)：** **µmol/l** で表記（基準値：3.4–20.5 µmol/l）。

### 3. 糖・脂質代謝
- **空腹時血糖 (*Глюкоза натощак*)：** **mmol/l** 単位（基準値：3.3–5.5 mmol/l。18を掛けると mg/dL に換算）。
- **HbA1c (*Гликированный гемоглобин*)：** 過去1〜2ヶ月の血糖平均値（基準値：< 5.7%）。
- **脂質プロファイル：** 総コレステロール（< 5.0 mmol/l）、LDL、HDL、中性脂肪（< 1.7 mmol/l）。

## 4. 検査票のマーク：↑、↓、太字、基準値の読み方

ロシアの検査所では、基準範囲（*референсные значения*）から外れた項目を明確にマークします：

```
検査項目                測定値       単位           基準値範囲       判定記号
-------------------------------------------------------------------------------
Гемоглобин (Hb)         108          г/л            120 - 140        ↓ (Понижено)
Лейкоциты (WBC)         11.2         10*9/л         4.0 - 9.0        ↑ (Повышено)
СОЭ (Westergren)        24           мм/ч           2 - 15           ↑
Креатинин               78           мкмоль/л       44 - 80          
Глюкоза натощак         5.1          ммоль/л        3.3 - 5.5        
СРБ (CRP)               1.4          мг/л           < 5.0            
```

- **`↑` または `Повышено`：** 上限値を超えている状態。
- **`↓` または `Понижено`：** 下限値を下回っている状態。
- **太字またはアスタリスク (`*`)：** 医師の注意を喚起するための表示。

> **重要な医学的知識：** 矢印が付いているからといって、**直ちに深刻な病気であるとは限りません**。検査の基準値は健康な人の95%が含まれるよう統計的に設定されているため、完全に健康な人でも5%は自然と基準値からわずかに外れることがあります。

## 5. レッドフラッグ：直ちに救急医療が必要な危険値

軽微な数値の変動は定期受診時に相談すれば十分です。しかし、命に関わる異常値が見られる場合は、直ちに救急車を呼ぶ必要があります（**ロシアでは携帯から 103、固定電話から 03、または 112；日本国内では 119**）：

> **救急要請が必要な重大検査値：**
> - **重症貧血：** ヘモグロビン 70 g/l 未満で、安静時頻脈、めまい、失神（*обморок*）を伴う。
> - **重症血小板減少：** 血小板 20 × 10⁹/l 未満で、点状出血（*петехии*）や歯肉出血が見られる。
> - **発熱性好中球減少症：** 発熱（38.5°C超）かつ好中球絶対数 0.5 × 10⁹/l 未満（抗がん剤治療中の危険な合併症）。
> - **重症高カリウム血症：** カリウム 6.5 mmol/l 超（致死的不整脈の危険）。
> - **急性腎不全：** クレアチニンの急激な倍増と尿量の著しい減少（*乏尿・無尿*）。

## よくある質問 (FAQ)

### ロシアでは医師の紹介状なしで血液検査を受けられますか？
はい。民間の検査所チェーン（Invitro、Gemotest、Helix、Citylab）では、処方箋や紹介状なしで全検査を自費で自由に受けられます。公立診療所の **OMS** 保険適用による無料検査には、担当医（*Терапевт*）の電子紹介状が必要です。

### EMIASやGosuslugiで検査結果を確認するには？
モスクワ市内では、公式アプリ **EMIAS.INFO** または mos.ru ポータルの「電子カルテ」からダウンロードできます。ロシアの他地域では、国家ポータル **Gosuslugi.ru** の「健康」項目からPDFを取得可能です。

### なぜロシアの検査票はクレアチニンや血糖の単位が違うのですか？
ロシアの臨床検査室は国際SI単位系に準拠しているためです。クレアチニンはマイクロモル毎リットル（**µmol/l**）、血糖はミリモル毎リットル（**mmol/l**）、ヘモグロビンはグラム毎リットル（**g/l**）を用います。血糖を日本の mg/dL にするには18を掛け、クレアチニンは µmol/l の値を88.4で割ることで mg/dL に換算できます。
